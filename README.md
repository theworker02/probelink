# probelink

Probe structured JSON link payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/probelink/

## Install / run

```bash
git clone https://github.com/theworker02/probelink.git
cd probelink
node src/cli.js
node --test
```
